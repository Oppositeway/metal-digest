# Пайплайн

Скрипт `digest-write.mjs` читает `CLAUDE.md` и вставляет его в system-промпт Claude при генерации дайджеста.

### Критерии отбора новостей

Приоритет (по убыванию):
1. Релизы альбомов и EP с датой выхода
2. Анонсы туров и фестивалей с конкретными датами
3. Изменения составов групп (уходы, пополнения)
4. Стриминговые премьеры и официальные треки

Исключать:
- Слухи без подтверждённого источника
- Переиздания, ремастеры, юбилейные издания старых альбомов
- Новости о смертях (требуют отдельного формата)
- Дубликаты новостей из предыдущего дайджеста (сравнивать по заголовкам)
- Новости старше 3 дней от даты публикации

Состав выпуска: 5 новостей — 3 релиза/анонса + 1–2 тура.

### Формат дайджеста

**Заголовок:** `Дайджест: [краткая тема] — [месяц YYYY]`
Пример: `Дайджест: релизы апреля — апрель 2026`

Каждая новость — H2-заголовок + 2–4 предложения:
```
## Группа — Альбом (Лейбл, дата)

Текст. Текст. Текст.
```

Туры выносить в отдельный блок в конце:
```
## Туры: Группа1, Группа2

Текст о турах.
```

Frontmatter — заполнять полностью:
```yaml
---
title: '...'
description: '2–3 предложения, перечисление главных новостей.'
pubDate: 'YYYY-MM-DD'
type: 'digest'
tags: ['metal', ...жанры..., 'releases']
sources:
  - 'https://...'
---
```

### Правила тона

- Формальный, журналистский — без «мы», без личных обращений
- Стоп-слова из article-style.md действуют и здесь
- Названия групп и альбомов — на языке оригинала (английский)
- Текст — на русском языке
- Не пересказывать пресс-релизы дословно; переформулировать своими словами
