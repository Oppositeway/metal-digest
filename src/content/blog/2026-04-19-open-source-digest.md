**Linux Foundation запустил Project Glasswing.** Апрельский выпуск новостей Linux Foundation открывается анонсом Project Glasswing — инициативы по защите критической инфраструктуры средствами открытого ПО. Проект позиционируется как ответ на растущие требования к безопасности государственных и промышленных систем. В том же месяце прошёл MCP Dev Summit в Нью-Йорке, собравший полный зал разработчиков вокруг темы «Internet of Agents», а фонд x402 Foundation создан как нейтральная площадка для универсальных платёжных протоколов с открытым управлением.

**Открытые LLM вплотную приблизились к проприетарным моделям.** По данным modemguides.com, апрель 2026 года стал поворотным: разрыв в бенчмарках между лучшими открытыми и проприетарными языковыми моделями сократился до однозначных цифр на практически значимых задачах. Квантованная версия Qwen3.6-35B-A3B весом 20,9 ГБ, запущенная на MacBook Pro, в одном из тестов обошла Claude Opus 4.7 при генерации SVG-иллюстраций. Аналитики фиксируют, что вопрос сместился: теперь речь идёт не о том, «достаточно ли хороша открытая модель», а о том, какая из них подходит для конкретного железа.

**OSI сменила исполнительного директора.** 13 апреля 2026 года пост исполнительного директора Open Source Initiative занял Дуэйн О'Брайен — технолог и адвокат открытого кода с почти 25-летним стажем. Смена руководства совпала с выходом нескольких отраслевых отчётов: State of Open Source Report 2026 (OpenLogic), State of Open Source Licensing 2026 (Redmonk) и данных глобального опроса по политикам открытого ПО (DPGA).
